# Button

The Button component is a versatile, accessible button element that supports various styles and states.

##### Everything is a button

In principle, try to think of the most actionable elements as buttons. Thinking and building this way ensures we have the right touch target areas and user feedback. It also makes our experiences easier to localize and friendlier for people using screen readers.

## Usage

```jsx
import { Button } from '@lfv/elements/Buttons/Button';

<Button>
  Click me
</Button>
```

### Hierarchy

#### Primary Button

Use one primary button per context to allow users to take a specific action, move forward in a flow, acknowledge and dismiss, or finish a task.

#### Secondary Button

Secondary buttons are the bread and butter of the button world. Lean into them whenever possible. The gray background protection provides higher visibility, making them more accessible than tertiary buttons. 

<Button variant="secondary">
  Secondary Button
</Button>

Tertiary buttons are mainly used for dismissive actions that give users a way out of something, letting them do nothing, dismiss, or skip.

### States

#### Disabled

Disabled buttons can be confusing and frustrating for many users and can be difficult to spot for those with low vision. To make things easier, try to enable the button so users can tap it, and provide an error message if any information is missing or incorrect. If you must use a disabled button, include clarifying text, an error message, or a tooltip to explain why. That way, everyone can easily understand why the button is disabled.

## Accessibility

The Button component follows accessibility best practices:

- Uses semantic HTML (`<button>` element)
- Supports keyboard navigation
- Includes proper ARIA attributes
- Provides focus indicators

## Design Tokens

The Button component uses the following design tokens:

- **Border Radius**: `var(--border-radius)`
- **Padding**: `var(--spacing-sm)`, `var(--spacing-md)`, `var(--spacing-lg)`
- **Font Size**: `var(--font-size-sm)`, `var(--font-size-md)`, `var(--font-size-lg)`
