# Buttons

## 1. Overview

Our 8-bit button is a nostalgic nod to arcade days, pixel-perfect for game interfaces that want to scream *"Press Start!"* with attitude. It’s loud, blocky, and makes no apologies. Whether you're building a player dashboard, a giveaway trigger, or a minting interaction — this button gets clicked.

Think of it as the big red button in your interface design: obvious, satisfying, and too tempting not to hit.

---

## 2. Purpose & Philosophy

In a world of smooth gradients and ghost buttons, our 8-bit button breaks the trend with intentional blockiness and high-contrast borders. It’s a throwback *with intent* — signalling clear, gamified interactivity in lottery, blockchain, and gaming contexts.

- **Signal interactivity**: It should *look* like it does something.
- **Feel authentic**: This isn’t a CSS filter on a modern button — it's crafted to *look and behave* like it belongs on a Game Boy screen.
- **Boost user delight**: It's not just retro, it’s fun. Every click should feel like a coin drop.

---

## 3. Anatomy

The 8-bit button is made of the following pixel-perfect layers:

+----------------------+
| ████████████████████ | <- Outer Border (2px jagged style)
| █ Click Me! █ |
| ████████████████████ | <- Background fill (solid colour)
+----------------------+


- **Outer Border**: A chunky, high-contrast 2px stroke — jagged corners welcome.
- **Background Fill**: Solid block colours — no gradients allowed.
- **Text Label**: Centre-aligned, monospace or bitmap-style font (think *Press Start 2P* or *VT323*).
- **Focus Outline**: Hard-edged dashed border (optional but encouraged).

---

## 4. Usage Guidelines

- **Use it when**:
  - You want to lean into retro aesthetics for buttons tied to game mechanics (mint, spin, or transactions).
  - Your product embraces pixel art or arcade theming.
  - You need a high-contrast, visible action element in a themed UI.

- **Avoid when**:
  - Your interface is primarily minimalist or modernist.
  - You need subtle actions like “learn more” or “cancel”.

**Spacing tip**: Add generous padding inside — pixel buttons shouldn’t feel cramped. 12px x 16px padding is a good starting point.

---

## 5. Variants

| Variant        | Description |
| -------------- | ----------- |
| `primary`      | High-contrast fill, usually neon green, red, or yellow with black border. |
| `secondary`    | Muted fill (e.g., greys or blues), same border. |
| `disabled`     | Dithered grey fill, text colour reduced opacity. |
| `danger`       | Red fill, warning state — great for irreversible actions. |
| `success`      | Green fill, used post-action or confirmation. |
| `iconButton`   | Square button with only a pixel-style icon inside. |

---

## 6. Accessibility Tips

- Use `aria-label` for icon-only buttons.
- Maintain a minimum 4.5:1 contrast ratio for text and background.
- Provide a focus state that’s visually distinct — e.g., bright dashed outline or shadow pulse.
- Don’t rely on colour alone: shape and contrast are king in retro UIs.

## 9. Do’s and Don’ts

✅ Do

- Use for primary CTAs in pixel-art or retro UIs.
- Embrace bold colours and black outlines.
- Pair with pixel or monospace fonts.
- Test on both light and dark backgrounds for readability.

❌ Don’t

- Round the corners — seriously, that ruins the aesthetic.
- Use gradients or shadows (unless mimicking dithering).
- Shrink the padding to save space — let it breathe.
- Mix with ultra-modern components in the same UI unless you're going full Ready Player One.

## 10. Voice & Brand Personality Notes

Our 8-bit button is cheeky, bold, and unapologetically retro. It should evoke arcade nostalgia with blockchain speed. Text inside buttons should match the vibe: short, punchy verbs like “PLAY”, “SPIN”, “MINT”, or “START”.

🕹️ If your interface is the game board, this button is your player one's start button. Give it pride of place.

Stay pixelated. Stay clickable.
